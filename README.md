# TimeGuard

Офлайн-контроль времени за компьютером для Windows. Приложение родителя выдаёт коды, а клиент на ПК ребёнка учитывает время и показывает экран блокировки. Основные команды времени работают без сети. Просмотр истории приложений использует локальную сеть.

## Установка

Готовые универсальные установщики доступны в [последнем GitHub Release](https://github.com/kbelousov-ency/TimeGuard/releases/latest):

- [**TimeGuard-Parent-Setup.exe**](https://github.com/kbelousov-ency/TimeGuard/releases/latest/download/TimeGuard-Parent-Setup.exe) — приложение родителя.
- [**TimeGuard-Client-Setup.exe**](https://github.com/kbelousov-ency/TimeGuard/releases/latest/download/TimeGuard-Client-Setup.exe) — служба и агент на ПК ребёнка.

Все зависимости, включая .NET, встроены в установщики. Отдельно устанавливать .NET или переносить папку с DLL не нужно. На ПК ребёнка при первой установке нужно передать **EXE и файл сопряжения JSON**.

### ПК родителя

1. Запустите `TimeGuard-Parent-Setup.exe`.
2. Откройте TimeGuard, задайте название клиента и мастер-пароль, создайте пару.
3. В разделе «Настройка клиента» нажмите **«Экспортировать файл сопряжения…»**.
4. Сохраните JSON и перенесите его вместе с клиентским установщиком на ПК ребёнка.

Приложение устанавливается для текущего пользователя в `%LOCALAPPDATA%\Programs\TimeGuardParent`. Создаются ярлыки в меню «Пуск» и на рабочем столе.

### ПК ребёнка

1. Запустите `TimeGuard-Client-Setup.exe` и подтвердите запрос администратора.
2. Запустите установщик в текущей учётной записи Windows. Имя вручную вводить не нужно: установщик сам привязывает ограничение к текущему пользователю.
3. Выберите экспортированный **файл сопряжения `.json`** через кнопку обзора.
4. Текущая учётная запись должна быть стандартной, без прав администратора.

Служба и агент устанавливаются в `Program Files\TimeGuard`. Служба автоматически запускается вместе с Windows и запускает агент в сессии ребёнка.

Файл сопряжения содержит секрет пары. Храните его у родителя, после настройки уберите копию с ПК ребёнка и носителя. Для второго родительского ПК установите родительское приложение и выберите «Импортировать файл сопряжения…» при первой настройке — новую пару создавать не нужно.

### Обновление и удаление

Для обновления запустите новый EXE-установщик поверх установленной версии. Имя учётной записи не запрашивается, поле файла сопряжения можно оставить пустым, чтобы сохранить текущую пару.

Актуальные установщики публикуются в разделе [Releases](https://github.com/kbelousov-ency/TimeGuard/releases).
Родитель обновляется запуском `TimeGuard-Parent-Setup.exe`. Клиент обновляется запуском
`TimeGuard-Client-Setup.exe` в текущей учётной записи с пустым полем файла сопряжения.
Состояние времени, сопряжение и журнал сохраняются. Новая версия выпускается тегом `v*`, после чего
GitHub Actions собирает и прикрепляет оба установщика к релизу.

Удаление доступно через список установленных приложений Windows. Данные пары и остаток времени сохраняются. Полный цикл установки и удаления клиентской службы следует проверить на целевом ПК: сборка установщика сама по себе не заменяет эту проверку.

## Использование

- Индикатор в углу показывает оставшееся время. Нажмите **на сам таймер**, чтобы открыть ввод кода и продлить время заранее.
- Обычный код содержит 9 цифр, резервный — 10. Можно ввести код с дефисами. Полученные минуты **добавляются к текущему остатку**; пока окно ввода открыто, таймер продолжает идти.
- Когда время заканчивается, появляется дневной экран блокировки с полями кода и мастер-пароля. Нажмите «Разблокировать». Достаточно одного способа; если заполнены оба поля, приоритет у мастер-пароля.
- Мастер-пароль днём добавляет 120 минут.
- Учёт времени не зависит от активности мыши и запущенных приложений. При блокировке Windows время не списывается.

### История приложений

Во время списания времени служба фиксирует приложения в сессии ребёнка. Для каждой записи сохраняются
программа, PID, дата и время запуска, а после завершения процесса — дата и время закрытия.
В родительском приложении нажмите **«История приложений»**, укажите имя или IP компьютера ребёнка
и нажмите **«Обновить историю»**. Оба компьютера должны быть в одной сети. Служба использует TCP-порт
`38765`, установщик добавляет разрешение для профиля сети «Частная». Запрос подписывается секретом пары.

### Ночной режим

По умолчанию действует с **21:00 до 09:00** по местному времени. Появляется отдельный ночной экран; **поля кода на нём нет**. Продление нажатием на таймер также недоступно.

Ночью обычные и резервные коды не принимаются. Мастер-пароль снимает ночной запрет до утра, время ночью не списывается. Расписание на экране берётся из конфигурации службы.

Для изменения расписания выполните от администратора и перезапустите службу:

```powershell
& "$env:ProgramFiles\TimeGuard\TimeGuard.Service.exe" --set-curfew 21 9 on
Restart-Service TimeGuard
```

Для выключения ночного запрета используйте `off` вместо `on`.

### Коды и ограничения

Обычные коды действуют примерно 10 минут, допуск расхождения часов ПК — около ±10 минут. Повторное использование отклоняется. Резервные коды экспортируются родителем, не имеют срока действия и также одноразовые.

Ограничение действует на выбранную учётную запись. Защита рассчитана на ребёнка без прав администратора. Ctrl+Alt+Del не перехватывается приложением; абсолютная защита от обхода не обеспечивается.

## Разработка

Подробная архитектура, история исправлений и технический долг — в [PROJECT.md](PROJECT.md).

| Проект | Назначение |
|---|---|
| TimeGuard.Core | Коды, учёт времени, состояние и IPC |
| TimeGuard.Service | Windows-служба, хранение, запуск агента |
| TimeGuard.Agent | Таймер, продление и дневной/ночной экраны |
| TimeGuard.Parent | Создание пары, экспорт JSON, генерация кодов |

Целевая платформа — .NET 8 / Windows x64. Для решения `.slnx` нужен SDK с поддержкой формата (9.0.200+).

```powershell
dotnet build TimeGuard.slnx -c Release
dotnet test tests/TimeGuard.Core.Tests -c Release
powershell -NoProfile -ExecutionPolicy Bypass -File installer\build-installers.ps1
```

Для сборки EXE нужен Inno Setup; путь к `ISCC.exe` можно передать параметром `-Compiler`. Локальный путь по умолчанию — `installer/tools/Inno/ISCC.exe`. Результаты — в `installer/dist`, промежуточные публикации — в `installer/stage`.

Иконка приложений и установщиков: `assets/app.ico`, созданная из `assets/app.png`. Скрипты PowerShell сохраняются в UTF-8 с BOM для Windows PowerShell 5.1.

Превью реальных экранов WPF без запуска блокировки:

```powershell
& .\src\TimeGuard.Agent\bin\Release\net8.0-windows\TimeGuard.Agent.exe --render-previews 'E:\My projects\TimeGuard\design-preview'
```

## Несколько клиентов и смена пароля

На главном окне родителя выберите клиента в списке. Коды, экспорт JSON и настройки относятся к выбранному клиенту. «+ Добавить клиента» открывает создание новой пары или импорт существующего JSON. Каждый новый клиент получает собственные секрет и ID. Импорт уже известного ID обновляет профиль без дубликата. Последний выбранный клиент сохраняется.

Прежняя одиночная пара загружается автоматически; перед миграцией сохраняется зашифрованная копия `parent.dat.single-client-backup` рядом с `parent.dat`.

Для смены мастер-пароля выберите клиента, откройте «Настройки», введите текущий пароль, новый пароль и повтор. Нажмите «Сменить пароль и экспортировать JSON…» и сохраните файл.

Перенесите JSON на соответствующий ПК ребёнка и запустите **новый клиентский установщик** поверх установленной версии. Текущая учётная запись определяется автоматически, выберите новый JSON. До импорта действует прежний пароль; после импорта и перезапуска службы — новый. Остаток времени, использованные коды и ночное расписание сохраняются. Файл от другой пары отклоняется. Старые JSON содержат прежний пароль: не используйте их для последующего обновления.

Если этим клиентом управляют несколько родительских ПК, импортируйте новый JSON на каждом через «+ Добавить клиента». Офлайн-приложение не может автоматически подтвердить доставку обновления на другой ПК.

Главное окно родителя сохраняет компактную ширину около 610 DIP. Для текста используется Ideal-рендеринг WPF, а растровые изображения масштабируются отдельным качественным режимом. Для переключения/добавления клиента нажмите имя со стрелкой; резервные коды сохраняются кнопкой «Резервные коды» под кнопкой «Скопировать код».
